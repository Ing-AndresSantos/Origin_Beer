# Origin Beer Frontend - Guía de inicio rápido

## Requisitos
- Node.js 14+ instalado ([Descargar aquí](https://nodejs.org))

## Instalación (primera vez)
```bash
npm install
```

## Iniciar el servidor

### Opción 1: Comando npm (Recomendado - Funciona en todos los OS)
```bash
npm start
```

### Opción 2: Script Windows
Haz doble clic en `start-server.bat` o corre:
```bash
.\start-server.bat
```

### Opción 3: Script Mac/Linux
```bash
chmod +x start-server.sh
./start-server.sh
```

### Opción 4: VS Code Shortcut
Presiona `Ctrl+Shift+B` para ejecutar la tarea automáticamente

## El servidor abrirá automáticamente en:
🌐 **http://localhost:5500**

---

## Comandos disponibles
- `npm start` - Inicia live-server en puerto 5500
- `npm run dev` - Iniciar servidor en desarrollo
- `npm run serve` - Iniciar servidor genérico

## ¿Qué es live-server?
Proporciona:
- ✅ Auto-refresh en cambios
- ✅ Servidor web local
- ✅ Funciona sin conexión

---

**Nota:** Esta configuración es portátil. Puedes compartir la carpeta del proyecto en cualquier equipo y funcionará igual.
